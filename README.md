# Ledger

A personal finance app for Mac.

This page only hosts the downloads. The app's source code isn't public.

## Download
Get the latest version from **[Releases](https://github.com/noah-kh/ledger-releases/releases/latest)**. Download the `.zip` file listed under Assets.

## What you need
- A Mac with Apple silicon (M1 or newer)
- macOS 27 or later

## Install
1. Double-click the downloaded zip to unzip it.
2. Drag **Ledger** into your **Applications** folder.

## Opening it the first time
Ledger isn't from the App Store, so the first time you open it, macOS says it can't verify the app. To open it anyway:

1. Open Ledger. When the warning appears, click **Done** (not Move to Trash).
2. Open **System Settings → Privacy & Security** and scroll down to the Security section.
3. Next to the message about Ledger, click **Open Anyway**, then click **Open**.

You only need to do this once.

## Your data
Everything you enter stays on your own Mac. Nothing is uploaded anywhere.

## Updating
Download the new zip and drag the new Ledger into Applications, replacing the old one. Your data is kept.
